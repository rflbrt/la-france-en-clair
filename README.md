# StatPublique

Les statistiques publiques sur la France, expliquées simplement, avec leur source et leur historique : dette, chômage, inflation, population, retraites, immigration.

**Site : <https://statpublique.netlify.app/>**, et [tous les chiffres](https://statpublique.netlify.app/chiffres/).

Site indépendant et non officiel, sans lien avec l'Insee. Les données viennent de l'Insee, d'Eurostat et d'organismes publics français, indiqués sur chaque chiffre.
